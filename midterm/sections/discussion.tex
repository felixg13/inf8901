\section{Discussion}

This project has proven considerably more challenging than initially anticipated, presenting obstacles across theoretical understanding, research methodology, and technical implementation.

Reading and understanding the foundational articles presented significant challenges. The theory of stochastic processes required for comprehending GPIS extends beyond my current mathematical background, necessitating a step back to strengthen fundamental concepts before approaching the advanced material. As my first foray into formal research, I initially struggled with efficient article analysis strategies. Through experimentation, I have adopted a two-pass strategy: first, an initial read-through without notes to grasp the overall structure and argument; second, a detailed pass where I condense each paragraph into a single sentence using Obsidian for note organization.

Developing the proof of concept for Mitsuba 3 presented substantial technical hurdles. The build environment proved particularly challenging, requiring precise version matching across GCC, CMake, Ninja, and Embree. Furthermore, the limited documentation for Mitsuba 3's C++ interface necessitated reverse-engineering plugin functionality through code inspection. Additionally, mastering the DrJit syntax used throughout the Mitsuba 3 engine added another layer of complexity to the implementation process.

Despite these challenges, this research project has been intellectually stimulating and professionally rewarding. I have gained valuable exposure to cutting-edge directions in computer graphics research, particularly the integration of machine learning techniques to advance both photorealism and practical applications. The project required revisiting foundational concepts in path tracing algorithms and light scattering functions, which has strengthened my understanding of the advanced topics central to this work. Most importantly, this experience has developed my ability to engage with complex theoretical concepts and apply them to existing production codebases, a critical skill for graphics research and development.

While this project has been more demanding than expected, I anticipate significant results from the Mitsuba 3 integration of GPIS. Considerable theory remains to be explored that will enhance the rigor of the literature review, including the memory model used for light transport in \cite{seyb24from} and the more recent sparse convolution approach from \textcite{xu25practical}. These additions will provide a more complete theoretical foundation for the implementation work ahead.
